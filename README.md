# JW-Site

Supporting repository for AtlasIT front-end experiments and documentation alignment tasks.

## Purpose

This repo hosts:

- Early SvelteKit bootstrap explorations (PR2).
- Documentation alignment & cross-link scaffolding (PR6).
- Shared narrative docs that should not block the main Workers deployment cadence.

## Relationship to Project-AtlasIT

Production Workers and consolidated platform code live in the Project-AtlasIT repo. This repo does not deploy production services; it is a staging ground for upcoming UI work (see ROADMAP.md there or local docs/ATLASIT_ROADMAP_LINKS.md).
